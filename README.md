# gc_usm_debug_menu

This is debug menu of Ultimate Spider-man PC ported on Gamecube version 


Requirements

Gcit.exe for create gamecube iso's

Installation and Compiling 

1. run build.ps1 with powershell automatically generate a patched main.dol
2. extract original ultimate spider-man for gamecube.iso main folder of the repo downloaded with Gcit.exe
3. replece main.dol with patched main.dol on sys folder (subfolder of ultimate spider-man [GUTE52] if american version)
4. and rebuild iso with gcit.exe
5. enjoy
